cz-harness AI-native delivery harness

Turns a raw requirement into shipped, reviewed code through a strict spec-driven pipeline: phases 0–6 run once per project (Scope → Risk), then every Requirement-Deliverable (RD) loops through a resolved gate profile, Definition-of-Ready, a red→green→refactor Build, and a fixed-order Gate (AI review, then security if flagged, then human if configured) — phase 10 rolls up telemetry once the wave drains. Ten role-scoped subagents do the work under a hard L0–L4 delegation ceiling; enforcement lives in hooks, not just prompts — strict red-before-green and role boundaries aren't optional.
